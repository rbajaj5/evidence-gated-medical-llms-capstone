# Evidence-Gated Medical LLMs Capstone

This repository contains the Module 14 capstone package:

**Surrogate-Aware Runtime Assurance for Agentic Medical LLMs: Preventing evidence overclaiming in clinician-facing AI systems**

The project implements a synthetic runtime-assurance framework for medical LLM outputs. It tests whether an LLM-style claim is allowed, narrowed, audited, stress-tested, or denied based on evidence currency, endpoint strength, source-population context, privacy/consent boundaries, and proof/provenance status.
